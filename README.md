# VQL — Valynox Quant Language

VQL is a language for writing stock-selection strategies: score formulas, stock pools, backtest rules, screening and checks. It is designed to be written by AI from plain-language requests.

VQL（Valynox Quant Language）是寫選股策略的語言：分數公式、選股範圍、回測規則、篩選與檢驗都用同一套寫法，設計成讓 AI 照白話需求直接寫出來。

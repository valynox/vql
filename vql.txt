VQL (Valynox Quant Language) reference for AI authors. Plain text.
VQL is the stock-selection language of AlphaPrime Stocks. A person speaks plain words; you write VQL and pass it through MCP:
score formulas -> stock_backtest formulas; stock pool -> universe; exits -> exit_when / keep_when / grid; other backtest and screening arguments (portfolio, screen_gate, checks, check_params) -> advanced. Look things up with stock_formula_help (topic=noun query=<plain words> returns a ready formula).
Human editions: VQL.zh-TW.md, VQL.en.md. Example library (plain words -> formula): examples.json.
Every token you emit (operator names, column keys, units, argument names, error codes) is ASCII; users speak Chinese, so recipes keep the Chinese phrase as the key (白話 -> form).
Conventions: X = any numeric unit (not BOOL, not CODE). lb+N = adds N days of warm-up. Section 15 lists what is NOT writable yet; everything else compiles.

1. Model

- One grammar, four jobs: search (score formulas, higher ranks first; `formulas`, `trees_from`, section 10), backtest (`portfolio={...}`), screening (`screen_*`, metrics, section 11), checks (`checks`, `apx.check.v1`, section 11).
- Three name layers: atom (`LAG`, `WSUM`, `GT`), reserved function (built from atoms; `RET` = `apx.RET`), user function (`user.<author>.NAME`, stored with `my_stock_strategies_change action=install`).
- Data (obtained from outside, one set per market) is not a layer of computation: columns (section 7), the parent id `PARENT_ID(L)`, and 5 derived financial ratios (section 7, `FN_EP` etc.; noun list level `data`).
- No technical-indicator operators (RSI, MACD, Bollinger): build them from atoms as user functions.
- No node-count rule; one technical limit (section 13). Sectors/themes = correlation baskets (section 6) or class nouns `cls.NAME()` (section 8), never a hand-made list.
- Values in generation / backtest / stock pool: i64 fixed point, bit-identical every run.

2. Grammar

node  = column[:UNIT] | number[:UNIT] | NAME(params..., inputs...) | $param | "string"

- Parameters (integers) first, inputs after. Zero-input names keep `()`: `MONTH()`, `PARENT_ID(1)`.
- At most 2 inputs per operator. Two-parameter operators take two numbers: `RET_SKIP(252, 21, close)`.
- Column names are case-insensitive. `"string"` only inside `in {...}` or right of `==` / `!=` on a code column.
- `$param` and formal inputs only inside a user function body. A formula must contain a column.

Operator form = function form (same tree):

a + b  ADD      a - b  SUB      a * b  MUL      a / b  RATIO     a % b  MOD(a, b)
a > b  GT       a < b  LT       a >= b NOT(LT)  a <= b NOT(GT)
a == b NOT(OR(GT, LT))          a != b OR(GT, LT)
a && b MUL (both BOOL)          a || b OR       !a NOT           -a NEG
c ? a : b   FILL(MASK(c, a), MASK(NOT(c), b))   (c invalid -> invalid)
x in {v, ...}   BOOL, one node  (x invalid -> invalid)

Precedence low to high: `?:` < `||` < `&&` < `== !=` < `> < >= <= in` < `+ -` < `* / %` < unary `- !`. Left-associative. Parentheses group. `&&` and `||` do not short-circuit: an invalid side makes the result invalid.

Constants: `0.5:RATIO`, `20:DAYS`, `1:COUNT`, `0:PRICE`. A number without a unit takes the other side's unit (`close > 100`, `close / LAG(20, close) > 1.1`, `CLIP(close, 10, 100)`, `close + LAG(1, 5)`); as a bare multiplier or divisor it is RATIO. Scientific notation works (`5e9`). Large constants: 7 significant digits x 10^0..12.

Code columns `industry`, `market`, `common`, `symbol` (unit CODE): only `==`, `!=`, `in {...}`, or a group key. `market in {TW, TWO}`, `symbol in {"2330", "2317"}`, `industry in {24, 28}`. Accepted in conditions and in score formulas (there it becomes a BOOL column, part of the library identity). In a score formula the industry group key is `PARENT_ID(1)`.

Aliases: `DIV` = `RATIO`, `WMAX` = `ROLL_MAX`, `WMIN` = `ROLL_MIN`, `apx.NAME` = `NAME`. `GSUM|GCOUNT|GRANK|GMAX|GMIN|GSTD(first, x)`: `first` an integer without a unit = level; anything else = group key (prints as `GSUM_BY` ...).

Also accepted (same tree, prints canonical):

ROLL_SUM(N, x) = WSUM(N, x)          LE/GE/EQ/NE(a, b) = a <= / >= / == / != b
AND(a, b, ...) = a && b && ...       IF/IIF/WHERE(c, a, b) = c ? a : b
MIN/MAX(a, b, ...) = nested MIN2/MAX2 (per cell; N days: ROLL_MIN/ROLL_MAX; market: GMIN/GMAX(0, x))
GPCT(g, x)       percentile in group 0..1; g = level 0..4 or any key; GPCT(0,x)=CS_PCT(x), GPCT(1,x)=CS_PEER_RANK(1,x)
ROLL_MAX(N, c)   = WSUM(N, c) > 0          (c BOOL: true on some day)
ROLL_MIN(N, c)   = !(WSUM(N, c) < N)       (true every day)
ROLL_MEAN(N, c)  = RATIO(WSUM(N, c), N:COUNT)   (share of days)
c > 0 | c == 1 | c != 0 | c >= 1 = c       c == 0 | c < 1 | c != 1 | c <= 0 = !c
FILL(c, 0) = FILL(c, 0:BOOL)

Not aliases (error carries the rewritten form): MA SMA AVG MEAN TS_MEAN -> ROLL_MEAN(N, x); SUM TS_SUM -> WSUM; STD STDEV TS_STD -> ROLL_STD; TS_MAX TS_MIN TS_RANK -> ROLL_*; PCT_CHANGE ROC -> RET; SHIFT REF DELAY -> LAG(N, x); RANK PCT_RANK CS_RANK -> CS_PCT(x); lower-case names -> upper case, parameters first (`MA(close, 60)` -> `ROLL_MEAN(60, close)`).

One vocabulary: score formulas, conditions, screening and checks all use upper-case names, parameters first (`LAG(5, x)` shifts back; `ROLL_MEAN(63, r)`; `MIN(x)` aggregates, `MIN2(a, b)` two numbers). Screening and check names are case-insensitive; old lower-case screening forms (input first, `roll_mean(r, 63)`) still parse to the same tree, an integer constant is accepted on either side, and the old screening `lag(r, k)` (drop k cells) is `SKIP(k, r)`.

Canonical print (lists, reports) reads back to the same tree: function form, constants with units, `(x in {...})`, `col:AMOUNT`.

3. Units and invalid values

x1e6 fixed : PRICE QTY MONEY RATIO PCT INDEX
integer    : DAYS COUNT BOOL CODE AMOUNT(whole currency units; a MONEY column read as col:AMOUNT)

BOOL constants are 0 or 1 only (`2:BOOL` rejected, fix `1:BOOL`; a count is `2:COUNT`). MONEY holds about +-9.22e12; total columns above that are read as AMOUNT automatically. Per-share values (`eps`) never mix with AMOUNT. Money / shares is per-share money (`revenue / shares` = `FN_PS(revenue, shares)` except shares <= 0); per-share money and PRICE compare, add and divide; a company total against a price is rejected (use `FN_PS(total, shares)` or `RATIO(total, fund.mktcap)`). Average traded price is `VWAP(N)`.

Unit algebra:

ADD SUB MAX2 MIN2      (X, X) same unit -> X ; (MONEY, PRICE) -> MONEY ; (PRICE, MONEY) -> PRICE  (per-share money only)
GT LT (>= <= == !=)    (X, X) same unit -> BOOL ; (MONEY, PRICE) and (PRICE, MONEY) -> BOOL      (per-share money only)
MUL                    (RATIO|BOOL, X) -> X ; (X, RATIO|BOOL) -> X ; (BOOL, BOOL) -> BOOL ; (COUNT|DAYS, X) -> X ; (X, COUNT|DAYS) -> X
RATIO MULDIV           (X, X) same unit -> RATIO ; (X, RATIO) -> X ; (X, COUNT|DAYS) -> X ; (MONEY, QTY) -> MONEY (per share) ; (MONEY, PRICE) and (PRICE, MONEY) -> RATIO
LOGR                   (X, X) same unit -> RATIO
LOG, percentiles, z-scores, returns   X -> RATIO
SQRT                   RATIO|PRICE|QTY|PCT|MONEY|INDEX|COUNT|DAYS|AMOUNT -> RATIO
FLOOR ROUND CEIL       x1e6 X -> X (integer units: identity)
EXP SIN COS ATAN       RATIO -> RATIO
NEG ABS DIFF ROLL_*    X -> X          LAG  any non-CODE -> same
NOT BOOL -> BOOL       OR (BOOL, BOOL) -> BOOL
FILL (X, X) same unit incl. BOOL -> same        MASK (BOOL, any non-CODE) -> unit of 2nd
VALID, EV_CHANGE, in {...}   any incl. CODE -> BOOL

Rejected: `close + volume`, `close * volume` (use column `px.turnover`), `close / volume`. `total / shares` is per-share MONEY (`FN_PS` = the same with shares > 0 required). To compare different units convert first: `RATIO(a, LAG(N, a))`, `CS_PCT(x)`, `LOG(x)`.

Invalid: any invalid input -> invalid output. Sources: empty panel cell (before listing, halt, unpublished), window not full, any invalid cell inside a window, divide by 0, `LOG(<=0)`, `SQRT(<0)`, i64 overflow, non-member of a cross-section. Each atom floors once. Means (`ROLL_MEAN` `ROLL_STD` `XL_PARENT` `GMEAN_BY` `GSTD` `GSTD_BY` `CS_REL_PARENT` `CS_Z` `CS_PEER_Z` `CS_WINZ`) sum in 128 bits: never invalid from a big sum; `WSUM`/`GSUM` are.

VALID(x)      1 if valid else 0, always valid
FILL(x, c)    x if valid else c
MASK(c, x)    x if c valid and true else invalid       <- use for filters; MUL(cond, score) gives 0, which still ranks
EV_CHANGE(x)  1 on the day the value changes, always valid

Invalid cell: score formula = not ranked; stock pool / `hold` = out; `weight` = not bought. `!(cond)` drops cells where cond is invalid; `!FILL(cond, 0:BOOL)` keeps them.

4. Operators (201; the 5 derived-data ratios are in section 7)

Layer: `a` atom (smallest, implemented by the engine), `r` reserved (built from atoms; every one has its bit-identical atom definition in section 5), `d` data (obtained from outside, not a computation). Levels `L`: 0 whole pool, 1 industry, 2 market, 3 country, 4 global. Window N includes today. Cross-section / group members = in the stock pool that day and input valid.

Element-wise:

ADD(a,b) a | SUB(a,b) a | MUL(a,b) a | RATIO(a,b) a  b=0 invalid | NEG(a) a | ABS(a) a
MULDIV(K,a,b) a  K1..1e9  K*a/b, 128-bit product, floored once (K*a never overflows; annualise: MULDIV(4, ni, equity))
SQRT(a) a  a<0 invalid, output RATIO | LOG(a) a  a<=0 invalid | EXP(a) a RATIO->RATIO
LOGR(a,b) a  ln(a/b), rounded once, either <=0 invalid | FLOOR(a) a  toward -inf
MAX2(a,b) r | MIN2(a,b) r   (no BOOL) | SIN COS ATAN(a) a RATIO->RATIO

Compare, logic, validity:

GT(a,b) a | LT(a,b) a | NOT(a) a | OR(a,b) r   (AND = MUL of BOOLs)
VALID(x) a | FILL(x,c) a | MASK(c,x) a | x in {v,...} a  (IN_SET; never written as a call)

Time-series windows:

SLOPE(N,x) a N2..252 ->X per day   R2(N,x) a N3..252   MAXDD(N,x) a N2..252 positive

INV_VOL_KEY(N,x) a N2..1260 RATIO->COUNT weight key = floor(2^30 / vol), vol = floor(sqrt(sum x^2 / k) / 10) in 1e-5 clamped 1..65535 over the k valid cells; k < N/2 -> invalid. inv_vol weighting = INV_VOL_KEY(20, RET(1, close))
CORR(N,a,b) a N3..252   VOL_RATIO(N,x) r N1..252  x[t] / mean of previous N days

Recursion and reset:

SCANSUM(r,x) a   since r was last true (that day included): running sum   | invalid before the first true r; an invalid r or x breaks the chain until r is next true
SCANMAX(r,x) a   ... highest        SCANMIN(r,x) a   ... lowest

`RWIN(4, 1, x)` = trailing four quarters; `RWIN(12, 0, revenue_m)` = same month last year; `RWIN_PCT(12, revenue_m)` = monthly revenue YoY; `EWIN(4, 2, EV_CHANGE(revenue_m), RET(1, close))` = mean move on the last 4 revenue release days; `EWIN(4, 2, EV_CHANGE(revenue), RET(1, close))` = mean reaction on the last 4 quarterly-report days (<4 reports -> invalid). Groups:

GMAX(L,x) a   GMIN(L,x) a  (no BOOL)

GSUM_BY(k,x) GCOUNT_BY(k,x) GRANK_BY(k,x) GMAX_BY(k,x) GMIN_BY(k,x) GSTD_BY(k,x) a   key units CODE|COUNT|BOOL|DAYS; write GSUM(k, x)
GMEAN_BY(k,x) a  group mean; k = level 0..4 or key (as GSUM); any unit, 1 member counts; XL_PARENT(L,x) and GMEAN(L,x) = the same tree
GWMEAN_BY(k,w,x) a  weighted group mean; k as GMEAN_BY; member needs w > 0; sw=max(0,bitlen(max w)-20), sx=max(0,bitlen(max|x|)+20+bitlen(n)-62), floor(sum((w>>sw)(x>>sx))/sum(w>>sw))*2^sx, always valid for members; GWMEAN(L,w,x) L1..4 = the same tree as GWMEAN_BY(PARENT_ID(L),w,x)
ORD(k,x) a (key,X)->COUNT exact position in the key's group, 0 = largest, each group 0..n-1; ties by a fixed shuffle (same as the pick ranks); k = level 0..4 (0 whole market) or key; one member -> 0. Top 3 per industry: GTOP(3, 1, x)
GQUANT(q,first,x) a q0..100 first as GSUM (level or key): floor(q*(n-1)/100)-th smallest in group (as WQUANT); 50 median, 0 GMIN, 100 GMAX; no BOOL
GRESID(k,x,z) a (key,X,any number)->X  least-squares residual of x on [1,z] within k's group (k = level 0..4 or key, as GSUM); 1 member -> 0; x - group mean past i64 -> group invalid
PARENT_ID(L) d L1..4 ->CODE, group key only
GSUM_ALL(L,x) a  GCOUNT_ALL(L,x) a   members = every stock with x valid, stock pool NOT applied; written to every cell of the group; L=0 same value for every stock
CS_PEER_RANK(L,x) r L1..4 ->RATIO   CS_PEER_Z(L,x) a   CS_REL_PARENT(L,x) r  x - group mean   XL_PARENT(L,x) a  group mean

Group idioms: above the industry median `close > GQUANT(50, 1, close)`; minus the group median `x - GQUANT(50, k, x)`; percentile in group `RATIO(GRANK(k, x), ADD(SUB(GCOUNT(k, x), 1:COUNT), SUB(GCOUNT(k, x), 1:COUNT)))`; mean in group `GMEAN(k, x)`; cap-weighted mean in group `GWMEAN(k, fund.mktcap, x)`; z-score in group `GZ(k, x)`; size-neutral in industry `GRESID(1, x, LOG(fund.mktcap))`. Keys: `PARENT_ID(1)`, `CS_QCUT(5, ROLL_MEAN(20, volume))`, `close > open`, `MONTH()`, `0:COUNT` (one group), `CORR_GROUP(...)`. Do not rank by the percentile inside a group (every group's best ties at 1); rank by `x - group mean`; if you must (e.g. `CS_PEER_RANK(1, x)`), add `portfolio.tie_by` = the ranked value.

Calendar: `MONTH()` 1..12, `WEEKDAY()` 0..6 (0 Monday), `MDAY()` 1..31, `YEAR()`, all COUNT; `EPOCH_DAY()` DAYS since 1970-01-01 (calendar days); `DAY_INDEX()` DAYS, 0 on the first panel day.

Meanings: `stock_formula_help topic=noun name=<NAME>`. E.g. `NEG(LZ_C_DIFF(60, close))`, `MUL(LZ_ORDERED_DIFF(60, 80, close), RET(20, close))`, `MASK(LZ_LEADS_DIFF(60, 80, close, volume), RET(20, close))`.

`STATESCAN(x, up, lo)` (three inputs, same numeric unit -> X): per symbol along days; first day = up (state up); up: x < prev -> down, value lo, else max(prev, up); down mirrors (x > prev -> up, value up, else min(prev, lo)); any input invalid -> invalid, restart. Trailing stop: `STATESCAN(close, ROLL_MAX(20, close) * 0.9, ROLL_MIN(20, close) * 1.1)`. `SELECT(c,a,b)` r -> write `c ? a : b`; four-input `REC2` not accepted (`APX_UNSUPPORTED`).

5. Reserved functions as atoms

Every reserved function has a bit-identical atom definition (36; value, valid bits, unit). Calculator keys other atoms build (`OR MAX2 MIN2 SELECT DIFF COUNT MOD ROUND CEIL`) are reserved. `[when: ...]` = bit-identical within that range.

DIFF(N,x) = SUB(x, LAG(N,x))                      OR(a,b) = NOT(MUL(NOT(a), NOT(b)))
MAX2(a,b) = FILL(MASK(GT(a,b), a), MASK(VALID(a), b))   MIN2: LT instead of GT
SELECT(c,a,b) = c ? a : b = FILL(MASK(c,a), MASK(NOT(c),b))
ROLL_RANK(N,x) = RATIO(WRANK(N,x), 2*(N-1):COUNT)
CS_PCT(x) = RATIO(GRANK(0,x), MUL(2:RATIO, SUB(GCOUNT(0,x), 1:COUNT)))     CS_PEER_RANK(L,x): same with L
CS_REL_PARENT(L,x) = SUB(x, XL_PARENT(L,x))        CS_RANK_CHG(N,x) = SUB(CS_PCT(x), LAG(N, CS_PCT(x)))
CS_QCUT(N,x) = MIN2(MUL(CS_PCT(x), N:COUNT), N-1:COUNT)
CS_WINZ(k,x) = MAX2(MIN2(CS_Z(x), k/10:RATIO), -k/10:RATIO)

`RET`, `RET_SKIP`, `DIST_HIGH`, `DIST_LOW`, `FN_YOY` with N > 252 (up to 1,260) are expanded into their atom definition when the formula is read (nodes count as expanded); same definition and result for any N.

`ADD` / `SUB` / `DIFF` past i64 -> invalid, same as the reserved function; `MULDIV` multiplies in 128 bits, so no overflow conditions. `EV_DAYS_SINCE`, `EV_EARN_DRIFT` declare a warm-up of N days; their atom forms 0 / 1 day, same cell values.

Atoms formerly listed as reserved (16; names, parameters, results unchanged): `ROLL_MEAN XL_PARENT ROLL_STD CORR SLOPE R2 MAXDD BETA RESID_MOM CS_Z CS_PEER_Z CS_NEUTRAL_MODEL AMIHUD PARK GK EMA`. 6. Similarity (derived columns; only data before each period)

CORR_GROUP([lookback[, every[, step[, corr_bp[, quant]]]]], <formula>)   defaults 252, 126, 1, 3000, 1   -> CODE, group key only
CORR_SEED({"2330", ...}[, lookback[, every[, step[, quant[, how]]]]], <formula>)   defaults 252, 21, 1, 1, 0   -> RATIO -1..1

- `<formula>` = any numeric formula over panel columns, no nesting: returns `RATIO(close, LAG(1, close))`, volume change `DIFF(1, LOG(volume))`, heat `RATIO(volume, ROLL_MEAN(20, volume))`, monthly revenue growth `RWIN_PCT(12, revenue_m)` with `(1260, 126, 21, ...)`, flows `foreign_net`.
- Points = lookback / step in 20..1024 (quant 0: 20..500). `quant` 1 = ranks inside the window (any series), 0 = return style. `corr_bp` 3000 = 0.3. Seeds 1..64 codes. `how`: 0 seeds as one basket, 1 max, 2 mean, 3 min.
- Group = every pair at correlation >= threshold. A stock alone: `GRANK` invalid, `GCOUNT` = 1.
- In a score formula both are part of the library identity; inside a condition or `weight` they are not.
- Score vs group: `MASK(VALID(GRANK(k, x)), SUB(x, RATIO(GSUM(k, x), GSUM(k, MASK(VALID(x), 1:RATIO)))))`.
- Seed basket (conditions): `GSUM(CORR_GROUP(<formula>), symbol in {"2330", "2382", "3231"}) > 0`. Exclude it: `!FILL(<basket>, 0:BOOL)`. Without seeds: `GSUM(k, <BOOL per day and stock>) > 0`.
- Noise of unrelated series: about +-2 / sqrt(points) (40 points +-0.32, 252 points +-0.13).

- One of `rebalance_days` / `hold_days` / `rebalance_when`. One of `weight` / `weighting`. `exit_when` / `keep_when` / `exit_below` / `exit_above` with `hold_days`: each slice has its own entry prices and exits; a sold share is cash until that slice expires; `keep_when` runs on the slice's expiry; `reentry_days` blocks the same slice only. Plain "stop at -8% / take profit at +20%" = `exit_below` / `exit_above`; "only on a close below" = `exit_when`. `$name` works inside `exit_below` / `exit_above` too (same `grid`).
- Expression arguments accept `"expr"` or `{"expr": "...", "label": "one plain sentence for the user"}`.
- `rebalance_when` / `exposure` must be market-wide (calendar, `idx.*`, `MKT_MEAN`, `EW_INDEX`); otherwise `E_NOT_MARKET_WIDE`.
- State leaves: `pos.ret` (return since the entry fill, adjusted, costs excluded), `pos.peak_ret` (highest closing `pos.ret`), `pos.drawdown` (1 - value / best closing value), `pos.days` (closes since entry), `pos.rank` (place among candidates, 1 = best; `keep_when` only), `pos.held` (true).
- `pos.*` only inside comparisons `> >= < <=`: one side linear in them (coefficients within +-100), the other a constant or a market-only expression; comparisons joined with `&& || !`.
- Fills: selection after the close of the decision day, filled at the next open. Costs: buy 0.1425%, sell 0.1425% + tax 0.3% (ETF tax 0.1%); override with `config` `fee_bp_x100` / `tax_sell_bp_x100` / `tax_sell_etf_bp_x100`.
- Selection: candidates = in pool, score valid, pass `hold`; top `max_positions` by exact rank (one distinct position per stock per day): larger score -> larger `tie_by` (missing last) -> larger `mix64((entity_id<<32)^day)` -> smaller stock index. Never depends on codes or column order. With massive ties (bucket numbers, percentile inside a group) the shuffle picks: use continuous scores or give `tie_by`. `CS_PCT` / `pos.rank` ignore `tie_by`.
- Period (top-level `stock_backtest`): `backtest_from` / `backtest_to` (`YYYY-MM-DD`, `YYYY-MM`, `YYYY`) or `backtest_years`; earlier data only warms up; one library = one period.

10. Search

`trees_from`: `formulas` (`formulas=[...]`, each validated at plan), `nouns` (`nouns=[{"name":"user.me.N","bind":{"x":"close"},"grid":{"n":[60,120]}}]`, at most 20000 combinations), `sample` (random generation; `trees`, `seed`, `rounds` 1..1000).

Numbers to try inside a formula: write `$name`, values in the one `grid` (`portfolio.grid`): `formulas=["RET_SKIP($n, 21, close)"]`, `grid {"n":[126,252]}` = the two trees written directly (same identity; `nouns` is sugar for it). A name in a formula -> one tree per value; a name in hold / exposure / weight / exit_when / keep_when / exit_below / exit_above / sizing -> variants of each tree. `{"formulas":["RET($n, close)"],"portfolio":{"exit_when":"pos.ret <= -$stop","grid":{"n":[60,120],"stop":[0.08,0.1]}}}` = 2 trees x 2 variants. Same name on both sides -> `E_GRID_SHARED`. Formula names: <= 256 values each, <= 20000 trees, window lengths OK. Plan: `effective.formula_grid`.

Search near the original: `apx.EVOLVE(x)` (also `EVOLVE(x)`, one argument) wraps one number or column; removing it = the starting formula (same identity). Operator parameter -> 2 grid points each side (`RET(apx.EVOLVE(60), close)` = `RET($n, close)` + `grid {"n":[20,40,60,120,252]}`, same trees and result; packed parameters change only the wrapped part); constant -> x 1/2 3/4 7/8 9/8 5/4 3/2 2 (days / counts: day grid); column -> every panel column of the same unit and kind. Candidates must compile, have a numeric root and fit the warm-up. Several positions multiply (first in text outermost); `$name` substituted first. Plan: `effective.formula_grid.evolve` (per position: `kind`, `from`, `values`). Wrapping an expression or anything in `universe` -> `APX_UNSUPPORTED`. In portfolio rules only a threshold number: `pos.ret <= -apx.EVOLVE(0.08)` = `$evolve1` with grid [0.04 .. 0.16]; integers in `apx.PICK` / `apx.EVERY` use the day grid; an operator parameter -> `E_EVOLVE_WINDOW`.

Each tree tries a base grid of portfolio settings, default 16: long threshold apx.IN_TOP 160 / 170 / 180 / 190 x rebalance 5 / 21 x positions 20 / 50; `screen_pick` keeps one. Each axis is a `$name` + `grid`: `apx.IN_TOP($pl)` in hold, `apx.EVERY($reb)`, `apx.PICK($n, ...)`, key `$wk == 0 ? 1 : apx.INV_VOL_KEY()`; only `grid` = `{"grid":{"reb":[5,10,21]}}` (names pl / reb / n / wk). One value = the plain number (same library). Those $names only in those places. apx.RANK_KEY(p): p = the apx.IN_TOP p. apx.IN_TOP / apx.RANK_KEY only in portfolio. Portfolio rules (`exit_when` ...) apply to every strategy of the search, sampled or given.

Random generation: `config {"sample_new": bits}` 1 = also market-level columns, `MKT_MEAN`, `EW_INDEX` as leaves; 2 = `CORR_GROUP` as group key.

Admission thresholds are search arguments: sampled searches apply defaults (cross-section score >= 2000 bp, time score >= 2500 bp, novelty >= 5000 bp, net return > 0, IC t >= 4); given formulas and noun grids apply only thresholds that are stated.

Multiple testing: every (tree x portfolio setting x threshold set of `grid`) is one trial in the library's ledger (N); N_eff from correlations between trials; DSR, IC p_adj, PBO are computed and reported, not gating (put `DSR` in `checks` to gate).

- Call: `user.local.RSI(42, close)`; parameters first (omitted = defaults), inputs after; `user.local.RSI@1(...)` pins a version. `name@version` is immutable (new content = new version).
- `inputs[].unit`: a unit name or `X`. `params[]`: integers with `default`, optional `min`, `max`, `grid`.
